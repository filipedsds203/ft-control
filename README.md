# FT Control — versão final com ícone atualizado

Esta versão inclui:

- todos os ajustes anteriores de PWA para iPhone e Android
- safe area do iOS
- bloqueio de zoom por pinça e duplo toque
- formulário preparado para autofill/senhas
- novo ícone escolhido por você aplicado em:
  - header do app
  - tela de login
  - apple-touch-icon
  - favicon
  - manifest do PWA
  - ícones Android/iOS

## Arquivos para subir no GitHub (repositório `ft-control`)

```txt
index.html
manifest.webmanifest
sw.js
netlify.toml
README.md
icons/
```

## Observação

Depois de publicar no Netlify, no iPhone apague o atalho antigo e adicione de novo pela tela inicial para atualizar o ícone.
