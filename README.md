# FT Control — MVP

Aplicativo financeiro para controle de casal.

## Fase atual

Esta versão é um protótipo funcional em HTML, CSS e JavaScript puro.

- Frontend em arquivo único: `index.html`
- Salvamento local no navegador usando `localStorage`
- Sem backend ainda
- Sem banco de dados ainda
- IA ainda simulada/local, preparada para futura integração via backend

## Próximas fases

1. Subir este projeto no GitHub.
2. Publicar no Netlify.
3. Criar backend no Render.
4. Criar banco no Neon Postgres.
5. Conectar Groq pelo backend.
6. Migrar o salvamento local para banco real.

## Observação importante

Como esta versão usa `localStorage`, os dados ficam salvos apenas no navegador/dispositivo onde o app for usado.
Quando o backend e o Neon estiverem conectados, os dados passarão a ficar salvos na nuvem.
